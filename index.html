About Me

I'm a Software Quality Engineer / SDET based in Atlanta, Georgia (open to relocation), currently at Capgemini embedded with Inspire Brands, where I build and own test automation infrastructure across CI/CD, mobile, web and API systems.

I build full-scale automation frameworks from nothing. The platform started as a gap I kept running into: CI/CD orchestration, mobile device execution and test-management sync each lived somewhere different, and nothing joined them up. I designed the architecture, wrote it, and still own it as its primary contributor — it now runs across multiple production brand projects at Inspire Brands, including Sonic, Buffalo Wild Wings and Dunkin’. The Maestro E2E framework was the same story: none existed, so I built one, with smoke suites, shared flows, critical-path coverage and standardized runners other teams reuse.

The part I actually enjoy is the diagnosis. The interesting failures are rarely in the test — they're in the system around it: the “flaky” suite that turns out to be a race condition in the app, the pipeline that only fails on the first run of the day, the coverage number that looks healthy while measuring the wrong thing. I like the debugging that starts where the stack trace stops, and I'd rather fix a root cause than quarantine a symptom.

I've led cross-functional QA teams of up to 8 engineers, hold a B.Tech in Electronics & Communication Engineering from IIITDM Jabalpur (2019), and am AWS Certified Cloud Practitioner. I'm increasingly drawn to the platform side of this work — the pipelines, tooling and feedback loops that make other engineers faster — and I'm looking for roles in platform and developer productivity engineering.
